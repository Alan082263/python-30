# Day 4: Checkpoint (Days 1 to 3)

30 minutes, closed book. The aim is to find out what has really stuck, not to pass or fail.

## The rules

- **Closed book.** No `lesson.md`, no cheat sheet, no old problem files, no AI, nothing
  pasted in. Just you, Zed and the terminal.
- **Stuck? Move on and come back.** Skipping around is allowed. Guessing is allowed.
- **Running your code is allowed.** That's the point of the checks. Looking things up is not.
- **Don't ask me for hints** until you've finished. I'll check everything afterwards, and
  I'll be glad to explain whatever you missed.
- **Stop at 30 minutes** (set a timer). Whatever isn't finished, note it and stop. A problem
  you couldn't finish tells us something useful.

## The three problems

Work in the `day04` folder.

| File | Kind | What you do |
| --- | --- | --- |
| `p1_predict.py` | Predict the output | Write what each `print` shows BEFORE running the file |
| `p2_fix_the_bug.py` | Find and fix | One function, two bugs; the checks tell you when it's right |
| `p3_write_it.py` | Write from scratch | Write one function; the checks tell you when it's right |

Run a file like this:

```bash
cd ~/Projects/python-30/day04
python3 p2_fix_the_bug.py
```
